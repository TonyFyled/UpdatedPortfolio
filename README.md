# Adedamola Falade — Graphic Design Portfolio

A minimalist, high-contrast monochrome portfolio website for visual artist and graphic designer **Adedamola Falade**.

Live portfolio: Pure black & white aesthetic featuring an unconstrained 3-column masonry layout, interactive modal viewer with magnification, touch gestures, and full multi-device responsiveness.

## ✨ Features

- **Pure Monochrome Aesthetic**: Deep black & crisp white high-contrast visual design.
- **Unconstrained 3-Column Masonry**: Images retain their native form factors and natural proportions without distortion.
- **Bold Lightbox & Modal Viewer**:
  - Fullscreen high-resolution inspection.
  - Interactive click-to-zoom magnification.
  - Keyboard navigation (Arrow keys, Escape).
  - Mobile touch swipe gestures (Swipe left/right to browse, swipe down to dismiss).
- **Fully Responsive**:
  - Desktop (>1024px): 3-column masonry grid.
  - Tablet (681px–1024px): 2-column layout with adaptive navigation.
  - Mobile (≤640px): 1-column layout with hamburger drawer and fluid typography.
- **Direct Contact & Inquiries**: Email clipboard copy and direct links to social profiles (X/Twitter, Dribbble).

## 🚀 Local Development

Open `index.html` directly in any modern browser, or run a local static server:

```bash
# Python 3
python -m http.server 8080

# Or with Node.js
npx serve .
```
